# USB-C Flash Drive Backup System

## Overview
The USB-C Flash Drive Backup system provides an easy way to transfer restaurant data between your testing tablet and your development computer. Simply plug in a USB-C flash drive and the app will automatically create a backup.

## Features

### 🔌 **Automatic USB Detection**
- Detects USB-C flash drives when connected
- Works on Android tablets and Windows computers
- Monitors for drive connections in real-time

### 📦 **One-Click Backup**
- Single button to create complete data backup
- Includes all restaurant data (servers, runs, NPS, analytics)
- Creates timestamped backup files
- Generates README with restore instructions

### 🔄 **Easy Data Transfer**
- Copy backup files between devices
- Restore data on your development computer
- Maintains data integrity across transfers

## How to Use

### On Your Restaurant Tablet

1. **Connect USB-C Flash Drive**
   - Plug your USB-C flash drive into the tablet
   - The app will automatically detect the drive

2. **Create Backup**
   - Go to Settings → Admin → USB-C Flash Drive Backup
   - Tap "Backup to USB Drive"
   - Wait for backup completion

3. **Take Drive Home**
   - Safely eject the USB drive
   - Take it home with you

### On Your Development Computer

1. **Copy Backup File**
   - Insert the USB drive into your computer
   - Copy the backup file to your computer
   - The file will be in: `FoodRunsCounter/Backups/restaurant_data_YYYY-MM-DD_HH-MM.json`

2. **Restore in Emulator**
   - Open the Food Runs Counter app in your emulator
   - Go to Settings → Admin → Data Backup & Restore
   - Use "Import Backup" to select the file
   - Confirm restoration

## Technical Details

### 🔍 **USB Drive Detection**
- **Android**: Checks `/storage/usbotg`, `/mnt/usb`, `/media/usb`
- **Windows**: Scans drive letters A-Z for removable media
- **Validation**: Tests write permissions before using drive

### 💾 **Backup Process**
1. Creates comprehensive JSON backup using existing BackupManager
2. Copies backup file to USB drive
3. Generates README with restore instructions
4. Validates file integrity

### 🔒 **Data Security**
- Local storage only (no cloud transmission)
- Full data validation during backup/restore
- Automatic error handling and recovery

## Troubleshooting

### ❌ **USB Drive Not Detected**
- Ensure USB-C flash drive is properly connected
- Try different USB-C port on tablet
- Check if drive is formatted (FAT32 recommended)
- Restart the app and try again

### ❌ **Backup Creation Failed**
- Check USB drive has sufficient space (minimum 10MB)
- Ensure drive is not write-protected
- Try a different USB-C flash drive
- Check tablet storage permissions

### ❌ **Restore Failed on Computer**
- Verify backup file is not corrupted
- Ensure emulator has proper file access permissions
- Try copying backup file to emulator's Downloads folder first
- Check backup file format (should be .json)
